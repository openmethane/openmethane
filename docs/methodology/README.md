# Methodology notes

Background material on the science behind Open Methane, written for a general
audience rather than for developers.

These are working documents rather than maintained reference documentation, and
predate much of the current implementation. They describe the *method*, which
has not substantially changed; they are not a reliable guide to the *code*.
These are legacy documents and will eventually be replaced with purpose-made
docs.

- [`methodology-website.md`](methodology-website.md) — prose explanation of the
  method: how initial emissions estimates are built, how the atmospheric model
  is used, and how observations correct the estimate. Written as copy for the
  Open Methane website.
- [`methodology-notes.org`](methodology-notes.org) — earlier authoring notes for
  the above, including suggestions for diagrams and illustrations.

For how the method is actually implemented, see [Overview](../overview.md) and
[Architecture](../reference/architecture.md).
