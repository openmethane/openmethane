Changed the CAMS download to fetch the field at 00:00 after the last day, so the last day's 24:00 boundary record follows CAMS too.

- Previously, the last day's 24:00 boundary record repeated the last CAMS field before it: 21:00 for EAC4, 18:00 for the forecasts, and 18:00 for the inversion when a run ended on the last day of a month, which includes every monthly run.
- The download now makes one more request for that step. For the inversion, at a month end, that means downloading the next month's 2.2 GB global file as well, since the inversion can only be downloaded a month at a time.
- If the step is not available yet, the download goes ahead without it and logs a warning, and `setup_for_cmaq.py` warns that the 24:00 record repeats the last field.
- To pick up the extra step, delete a staged `CAMS_FILE` and download it again.

Note: boundary values in the last few hours of each run change slightly.
