Quote the `--source` glob passed to `tropomi_methane_preprocess.py` in
`scripts/run-all.sh`.

Unquoted, the shell expanded the glob and `tropomi_methane_preprocess.py` received
the first match as `--source` and the rest as positional arguments, failing with
"Got unexpected extra arguments" as soon as more than one granule was fetched. It
went unnoticed because the au-test domain matches a single granule on the date the
end to end test uses.
