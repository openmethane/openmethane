Changed the daily boundary condition files to follow CAMS through the day.

- Previously, each day's BCON held the CAMS methane field from the start of the day for all 24 hours,, so the boundary jumped at each midnight.
- Each day's BCON now has a record at every CAMS time from 00:00 to 24:00 (3-hourly for EAC4, 6-hourly for the inversion and forecasts), and CMAQ interpolates between them. Runs can have any number of boundary control steps, and steps need not start at midnight.
- BCON files staged before this change are still time-independent. Delete them and rerun `setup_for_cmaq.py` before a run with more than one boundary control step, because it skips existing files when `FORCE_UPDATE` is false.

Note: the boundary methane changes, so posterior emissions differ from earlier releases. See [Boundary conditions](https://github.com/openmethane/openmethane/blob/main/docs/reference/boundary-conditions.md).
