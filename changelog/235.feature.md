CMAQ's MPI domain decomposition can now be derived from the size of the domain.
Setting `NUM_PROC_TOTAL` to the number of cores available splits the domain into
that many subdomains, using fewer ranks when the domain is too small to be split
that finely, so the same setting suits every domain. `NUM_PROC_COLS` and
`NUM_PROC_ROWS` still pin the decomposition when they are set.
