Changed the test suite to run everything by default, including the WRF integration test, except `tests/integration/fourdvar`. Tests are marked by what they need or cost (`network`, `wrf`, `cmaq`, `adjoint` and `slow`), so a quicker run can leave some out with `-m "not slow and not network"`, and `make test-wrf` was removed. See [Running the tests](https://github.com/openmethane/openmethane/blob/main/docs/guides/development.md#running-the-tests).
