Store the TropOMI column mixing ratio precision with each observation.

`methane_mixing_ratio_precision` was read from the retrieval and used to
initialise the observation's `uncertainty`, but `add_visibility` then replaced
that with a constant 20 ppb standing in for the whole error budget, so the
retrieval's own precision was discarded and never reached the observation file.
It is now kept in its own `ch4_column_precision` field alongside the uncertainty
the inversion weights by, and is archived with the observations.

For the 2022-12-07 test granule the precision runs from 1.5 to 2.2 ppb, well
below the 20 ppb assumed, so the constant is dominated by representativeness and
model error rather than retrieval noise. Nothing uses the stored precision yet;
it is there so that a real error model can be built without reprocessing.
