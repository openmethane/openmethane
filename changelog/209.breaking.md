Fetch TropOMI methane data from the public `meeo-s5p` S3 bucket instead of the
NASA GES DISC subsetting API, which no longer performs the spatial crop the
pipeline relied on.

The bucket is anonymously readable, so `EARTHDATA_USERNAME` and
`EARTHDATA_PASSWORD` are no longer used and have been removed from
`.env.example`. Remove them from your `.env` file and from any deployment
configuration.

Granules are now downloaded whole rather than cropped to the bounding box.
Granules that do not overlap the box at all are discarded, and
`tropomi_methane_preprocess.py` drops the remaining out-of-domain observations
as it already did.

This changes retrieved methane values for small domains. `destripe_smoothing`
estimates the stripe pattern from a median over +/-100 scanlines along track, so
only pixels within 100 scanlines of a crop boundary can change; pixels further
in are unaffected. For the `aust` domain the boundaries fall over ocean and no
observations passing the quality filter lie in that band, so values are
unchanged. For a domain shorter than 200 scanlines, such as `au-test`, every
pixel is within the band and values shift by of order the single-pixel
precision. Whole granules give `destripe_smoothing` the along-track window it
assumes, so the new values are the more defensible ones.
