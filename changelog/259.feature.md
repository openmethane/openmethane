`WRITE_VADV_TOPFLX` makes each forward run write a gridded file of the advective flux through the model top, holding the upward and downward transport of methane and of air separately. It is off by default. When it is on, each forward pass keeps its own copy under `{CMAQ_BASE}/output/vadv-topflx/<pass>/`, together with the domain-integrated per-interface flux records taken from that pass's CMAQ log, so a whole inversion's worth can be collected from the run directory afterwards rather than only whatever the last forward pass left behind.
