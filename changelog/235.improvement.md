The Docker image temporarily starts through a debugging entrypoint,
`scripts/docker-entrypoint-debug.sh`, which logs an `[om-metrics]` JSON line
when a container starts and finishes, recording wall time, CPU time and mean
parallelism, CPU throttling, memory use and whether the run pushed against its
memory limit. This is to gather the data needed to choose `NUM_PROC_TOTAL` and
instance sizes, and will be removed once it has. Set `OM_METRICS=0` to turn the
logging off.
